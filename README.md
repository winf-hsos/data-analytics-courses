# Datenanalyse mit R

Euer Arbeitsordner für die Module zur Datenanalyse von Nicolas Meseth an der Hochschule Osnabrück: „Werkzeuge der Markt- und Gesellschaftsforschung“, „Praxis der Markt- und Gesellschaftsforschung“, „Empirisches Arbeiten“ und „Big Data Analytics“. Ihr öffnet ihn zweimal: in **Positron** zum Arbeiten und in **OpenCode**, wo euer Kursassistent läuft.

## Was hier drin ist

| | |
|---|---|
| `my-code/` | **euer Ordner.** Eure Skripte, eure Kopien der Vorlagen, später euer Bericht. |
| `data/` | hier legt ihr die Kursdaten aus ILIAS ab. Sie sind nicht öffentlich und deshalb nicht in diesem Repository. |
| `course/` | das Kursmaterial aller Module. Euer Assistent liest es; ihr ändert es nicht. |

Alles andere ist für den Assistenten und OpenCode. Das könnt ihr ignorieren.

## Loslegen

1. OpenCode installieren: [opencode.ai/download](https://opencode.ai/download). Das ist das Einzige, was ihr von Hand installiert.
2. Diesen Ordner herunterladen: grüner Knopf **Code**, dann **Download ZIP**, und die ZIP-Datei **entpacken** (Windows: Rechtsklick, *Alle extrahieren*).
3. Den Ordner in OpenCode als Projekt öffnen, eine neue Sitzung starten und `/onboarding` tippen. Der Assistent fragt, in welchem Modul ihr seid, sieht nach, ob Positron, R und Quarto schon da sind, installiert mit euch, was fehlt, und führt euch von da an.

Die Kurse starten mit einem der freien Modelle, die OpenCode mitbringt; ihr braucht dafür keinen Schlüssel.

Jeder Schritt mit jedem Klick: `course/material/software.md`.

## Aktualisieren

Wenn Nicolas es ansagt, tippt ihr in OpenCode `/update-semester`. Eure Ordner `my-code/` und `data/` werden dabei nie angefasst.

## Die Befehle

| Befehl | wofür |
|---|---|
| `/onboarding` | der erste Start: Modul, Positron, R, Quarto, Pakete, Daten, Systemcheck |
| `/self-study` | begleitet euch durch das Selbststudium eures Moduls |
| `/final-check` | schließt das Selbststudium ab: Selbsttest prüfen, kurzes Gespräch über euren Code |
| `/update-semester` | holt neues Material |
