# my-code: euer Ordner

Alles, was ihr in diesen Kursen schreibt, gehört hier hinein.

- Eure R-Skripte, etwa `session_1.R` aus der ersten Sitzung.
- Eure Kopien der Vorlagen eures Moduls, etwa `self-test/`.
- `about-me.md` legt der Assistent bei `/onboarding` an. Darin merkt er sich, in welchem Modul ihr seid, was ihr mitbringt und woran ihr gerade arbeitet. Ihr dürft sie jederzeit lesen, ändern oder löschen.
- `ai-log.md`, wenn ihr eins führt: wo ihr einen Vorschlag des Assistenten korrigiert oder verworfen habt, und warum.
- `systemcheck.txt`, das Ergebnis des Systemchecks.

Updates des Kurses (`/update-semester`) ändern oder löschen hier nichts, außer dieser README.

Alles außerhalb dieses Ordners und außerhalb von `data/` gehört zum Kurs und wird bei jedem Update ersetzt.

**Namen im Code sind englisch**, in `snake_case`: Dateien wie `session_1.R`, Objekte wie `survey` oder `mean_age`. Die Regeln stehen in `course/material/r-conventions.md`.
